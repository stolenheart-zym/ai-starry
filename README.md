# 智涌星河 —— 人工智能与新质生产力 · 可视化叙事网站

> 以梵高《星月夜》为灵感的滚动式数据可视化网站
> 课程作业 · 可视化导论 | 纯前端实现 · 零依赖构建 · 双击即可运行

## 一、创意理念

**「把数据画成星河」** —— 这是整个网站的设计原点。

梵高把星光画成流动的河；我们把数据画成流动的星河。网站通篇以**流动的星空**为视觉主线，将「人工智能作为新质生产力的作用与意义」拆解为 8 个章节（8 颗亮星），用户**滚动鼠标**即可完成一次从「启明星升起」到「引力之约」的星际航行。每一张图表都不是孤立的统计图，而是从星空中「生长」出来的天体：

- 市场规模 → 奔涌的**星河**（河流图）
- 行业应用 → 可点击的**星宿星座**（星座图 + 雷达图）
- 中美对比 → 交相辉映的**双子星**（双球 + 动画条形）
- 算力增长 → 持续爆发的**超新星**（粒子爆炸 + 对数曲线）
- 生产力提升 → 散落的**星尘**（米特环）
- 要素聚集 → 光标的**引力场**（物理粒子交互）
- 发展历程 → 横贯天际的**星辰轨迹**（时间线）

## 二、关键亮点（10 项）

### 1. 全程梵高《星月夜》动态背景（算法绘制）
背景不是贴图，而是**程序实时绘制**：由 6 个旋涡中心构成的速度场驱动 700 个「笔触」粒子，在画布上留下梵高式的流动笔痕；明月带三层光环、10 颗星辰闪烁呼吸、银河带沿贝塞尔曲线铺展、山丘上的村庄灯火明灭、丝柏树如火焰伫立，还有随机划过的流星。鼠标移动会产生视差——整个星空会「跟」着你看。

### 2. 滚动驱动的章节叙事
8 个章节由 IntersectionObserver 驱动：右侧 8 颗星点导航随滚动点亮、左下角章节名实时切换、顶部「彗星」进度条随滚动划过天际。所有文字、面板以错落节奏淡入上升，形成「星际航行」的节奏感。

### 3. 星河河流图（市场规模可视化）
全球 AI 市场（2019—2030）与中国 AI 核心产业（2020—2025）画成两条**发光的星河**：面积渐变如星云，主线自带光晕，**星光粒子沿河流流动**；预测段以虚线区分；里程碑以「亮星」标记（ChatGPT 发布、「人工智能＋」行动、核心产业破万亿），悬停任何位置即可查数并显示同比增速。

### 4. 星宿星座图（行业互动雷达）
7 大行业（制造 / 医疗 / 教育 / 农业 / 能源 / 交通 / 金融）以**星宿环**排列，星座连线若隐若现。**鼠标靠近星辰即放大并浮现介绍**；点击后金色光线从中心射向该星，中央**数字化雷达图平滑变形**为该行业的「应用深度 / 效率提升 / 成本优化 / 创新引领」四维画像，右侧面板同步展示该行业的效率数据。

### 5. 双子星对比（中美 AI 版图）
中国（金色「东方辰星」）与美国（青色「西方辉星」）双球对峙，中间能量桥流光涌动。**6 个指标按钮**（生成式 AI 专利、AI 投资、工业机器人装机量与密度、灯塔工厂、大模型数量）一键切换：双球按实力**缩放变亮**、条形图弹性伸缩、自动计算「中国 ≈ 美国的 X 倍」，数据全部标注来源。

### 6. 超新星爆发（算力革命）
进入章节瞬间，300 粒发光粒子**从核心爆炸**，冲击波扩散、核心脉冲——隐喻「AI 训练算力每 3.4 个月翻一番、8 年增长 30 万倍」的算力大爆发。每次进入页面都会重新点燃。

### 7. 对数算力曲线 + 智能算力柱状图
从 AlexNet（2012）到 Gemini Ultra（2024）的训练算力在对数坐标上画成陡峭上升的「火箭轨迹」，各模型如星点标注（悬停显示 FLOPs）；中国智能算力（2022—2025）柱状图逐根生长，标注 2024 年 74.1% 的增速。

### 8. 星尘引擎（生产力实证）
麦肯锡「13 万亿美元」大数字滚动浮现；6 个**米特环**（环形进度）分别展示代码效率 +55%、制冷能耗 −40%、药物研发周期 −70% 等各领域实证，数字滚动、光环徐徐闭合；WEF 数据以「创造 1.7 亿 / 取代 9200 万 / 净增 7800 万」对比条呈现技术对岗位的双面影响。

### 9. 引力场交互（生产要素聚集）
**移动鼠标即成为引力源**：人才（金）、资本（青）、技术（紫）、数据（绿）四色粒子被光标俘获、旋绕、聚集——直观隐喻「生产要素向创新核心聚集」的新质生产力逻辑。

### 10. 星辰轨迹时间线 + 辩证收尾
2017 规划 → 2022 ChatGPT → 2023 新质生产力 → 2024「人工智能＋」→ 2024 诺奖 → 2025 大模型备案 → 2030 展望，7 个节点依次点亮；「直面挑战」与「拥抱未来」双卡并置，结语「人类的想象力，是宇宙中最亮的星」点题收束，页脚附全部数据来源。

## 三、技术实现

| 项 | 说明 |
|---|---|
| 技术栈 | 原生 HTML / CSS / JavaScript，**无任何构建依赖** |
| 图表库 | D3.js v7（本地化引入，离线可用） |
| 动效引擎 | Canvas 2D 粒子系统（自研涡流场）、SVG 描边动画、CSS 过渡 |
| 叙事引擎 | IntersectionObserver 滚动联动 + requestAnimationFrame 高性能渲染 |
| 交互 | 悬停查数、点击联动、鼠标视差、引力模拟、指标切换 |
| 适配 | 响应式布局（桌面 / 平板 / 手机）、`prefers-reduced-motion` 无障碍支持 |
| 代码结构 | `data.js`（数据层）→ `starry.js`（星空引擎）→ `charts.js`（图表引擎）→ `main.js`（叙事编排），四层分离 |

## 五、运行与发布

- **本地运行**：双击 `index.html` 即可（所有数据内联，无跨域问题）
- **发布**：整目录推送至 GitHub Pages 或任意静态托管
- **目录结构**：
  ```
  ai-starry/
  ├── index.html          # 主页面（8 章节结构）
  ├── css/style.css       # 设计系统与动效
  ├── js/data.js          # 数据层（全部数据 + 来源）
  ├── js/starry.js        # 梵高星空背景引擎
  ├── js/charts.js        # D3 图表引擎（10 种可视化）
  ├── js/main.js          # 滚动叙事编排
  └── lib/d3.min.js       # D3 v7（本地）
  ```
